Overview

This repository contains two beginner-friendly Python projects developed as part of the Month 1 Python Development Internship tasks. The projects demonstrate fundamental programming concepts, interactive user input, task management, and basic application testing.

Projects

1. Dice Rolling Game

A command-line game that simulates rolling two dice.

Features

- Generates random values between 1 and 6 for each die.
- Displays both dice results and their combined total.
- Allows the user to roll again.
- Handles different user responses.

Concepts practiced: Random number generation, loops, conditional statements, and user input.

File: "Task1_Dice_Game/dice_rolling_game.py"

2. To-Do List Application

A menu-driven application for managing a list of tasks.

Features

- Add and view tasks.
- Mark tasks as completed.
- Remove completed tasks.
- Display a text-based progress bar and completion percentage.
- Handle invalid menu choices and task numbers.

Concepts practiced: Functions, lists, dictionaries, loops, conditional statements, and input validation.

File: "Task2_Todo_App/todo_app.py"

Technologies Used

- Python 3
- Visual Studio Code
- Python standard library

How to Run

Install Python 3, then open a terminal in the relevant project folder.

Run the Dice Rolling Game:

python dice_rolling_game.py

Run the To-Do List Application:

python todo_app.py

On Windows, you can use "py" instead of "python" if needed.

Testing

Test each application's main features, including repeated dice rolls, task creation, task completion, task removal, and progress calculation. Screenshots should show actual program output.

Current Limitations

The To-Do List Application stores tasks in memory. Tasks are not saved permanently when the program closes.

Learning Outcomes

These projects provide practical experience with Python fundamentals, interactive command-line applications, problem-solving, input validation, and basic software testing.
